# 矿大307实验室

这里是中国矿业大学（北京）地球科学与测绘工程学院地理空间信息化实验室的 GitHub 组织。我们的研究涵盖数字地球空间建模、全球离散格网、时空 GIS 和遥感智能感知。

## 代表项目

| 项目 | 用途 |
| --- | --- |
| 对地观测卫星任务规划 | 在三维地球场景中组织观测目标和卫星资源，分析轨道与观测机会，并回放任务规划方案。 |
| 全球离散格网（DQG）SDK | 为层次化球面格网提供空间索引，用于按尺度组织位置和格元。 |
| 三维 DQG 格网应用 | 为三维格网数据组织、场景展示与空间分析研究提供服务支持。 |
| 传统 GIS 平台建设 | 围绕图斑管理、管线管理和专题监测，开发地图展示、空间数据维护和业务管理功能。 |

## 代码发布

研究代码目前在实验室内部协作。后续计划在这里发布部分卫星强化学习研究代码。
